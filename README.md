# Fryga Claude Code Marketplace

A [Claude Code plugin marketplace](https://docs.claude.com/en/docs/claude-code/plugins) published by [Fryga](https://fryga.io).

## Plugins

### superpowers-rails

A Rails-focused fork of [Jesse Vincent's Superpowers](https://github.com/obra/superpowers) — the full Superpowers software-development methodology (brainstorming, planning, TDD, subagent-driven development) plus Rails convention skills, a rails-reviewer subagent, and vertical-slice planning. Source: [fryga-io/superpowers-rails](https://github.com/fryga-io/superpowers-rails).

## Install

```
/plugin marketplace add fryga-io/claude-marketplace
/plugin install superpowers-rails@fryga
```
